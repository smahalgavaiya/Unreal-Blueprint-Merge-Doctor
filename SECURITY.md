# Security Policy

## Supported versions

The latest published beta receives security fixes. Older prerelease builds are unsupported.

## Reporting a vulnerability

Do not include exploit details, private project data, credentials, or proprietary Unreal assets in a public issue.

Use GitHub's private vulnerability reporting feature on this repository when available. Include the affected version, Unreal Engine version, impact, reproduction steps using non-sensitive fixtures, and any proposed mitigation.

Blueprint Merge Doctor never requires Git credentials and does not invoke Git. If a build requests credentials or attempts to modify BASE, OURS, or THEIRS, stop using it and report the behavior.
